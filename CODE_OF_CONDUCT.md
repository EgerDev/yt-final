# Code of Conduct

## Scope

This applies to every project space — issues, pull requests, discussions, code
review, and commit messages — and to public spaces where someone is
representing the project.

## Expected behavior

- Address the work, not the person.
- Assume the other person is acting in good faith, especially when a report or
  a review reads as blunt. Written technical discussion loses tone.
- Accept that a maintainer may decline a change. The 1.0.0 compatibility and
  security contracts described in `README.md`, `SECURITY.md`, and
  `CONTRIBUTING.md` constrain what can be accepted, and "no" to a patch is not
  a judgement about the person who wrote it.
- Report defects with enough detail to act on: platform, version, and exact
  reproduction steps.

## Unacceptable behavior

- Harassment, insults, or personal, political, or identity-based attacks.
- Sexualized language or imagery, and unwelcome sexual attention.
- Publishing someone's private information — physical or email address, or
  anything else they have not chosen to share.
- Sustained disruption: reopening settled decisions without new evidence,
  or repeatedly reframing a technical disagreement as a personal one.
- Posting real credentials, cookies, session tokens, or unsanitized browser
  traces. This is both a conduct problem and a security one; see
  `SECURITY.md`.

## Legality and intended use

`yt_final` is a download and media-processing tool. Contributors are
responsible for using it lawfully and in accordance with the terms of the
services they access. Requests to add bot-detection evasion, CAPTCHA
circumvention, credential stuffing, or bulk scraping of other people's accounts
are out of scope and will be closed.

## Enforcement

Report a concern privately to the repository owner through GitHub rather than
in a public thread. Include links to the relevant messages. Reports are handled
confidentially; the reporter's identity is not shared with the person reported.

Maintainers may edit, hide, or delete contributions that violate this document,
and may block a participant. Responses are proportionate: a first, contained
lapse usually gets a private word, while sustained or severe behavior does not.

Enforcement decisions rest with the repository owner. This project does not
have a separate conduct committee, and this document does not create one.
