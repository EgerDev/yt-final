For editors NLE · markers · sidecars

Off by default. On, the delivered file is ffprobed and the job fails when it is under 1 KiB, has no audio stream, has no video stream (unless Max resolution is audio), or its duration is off by more than 1% of the video length (2 s floor, skipped for clips). It also fails when ffprobe is missing or errors — strict verification cannot pass a file it could not read. With it off the same mismatch is only a log warning. Delivery = “Download only” skips the check entirely: nothing is verified, not even a warning, because the post-processing stage that runs it never runs. The Will… line says so as “skips verification”.

Auto / Built-in = normal YouTube path. Hybrid (optional) inspects the format then may use turbo or aria2 when they fit. Force aria2/turbo pin one tool and fall back if missing/unsuitable.

On a throttling ISP (carrier/5G home), a proxy that exits on a remote server bypasses per-hostname video shaping for downloads only — no system-wide VPN. Simplest: ssh -D 1080 user@vps then socks5://127.0.0.1:1080.

Notify webhook on finish

POSTs when a job finishes (success or fail). Public https only — private/local URLs are blocked. Prefer Discord / ntfy / Slack.

Settings proxy · anti-throttle

If your ISP throttles YouTube (carrier/5G home internet), turn this on. The app runs a tiny local proxy that hides the video hostname from your ISP's traffic inspection, so downloads run at full speed. No VPN, no account, nothing to install — leave it on.

Resolves video hostnames through Cloudflare's encrypted DNS (1.1.1.1) instead of your ISP's, so an ISP that blocks or redirects by DNS can't interfere. Applies when the bypass (re)starts; falls back to normal DNS automatically. Leave off if downloads already work.

Passwordless only, applied to every download while checked. The local bypass above takes precedence when both are on. e.g. an SSH tunnel: ssh -D 1080 user@vps → SOCKS5 · 127.0.0.1:1080.

How to sign in

Auth stores YouTube cookies so age-gated and throttled videos can download. Cookies stay on this computer only.

What you need

  • Chrome (best), or Firefox / Brave / Edge
  • A YouTube account you can sign into
  • Nothing else - Playwright is not required

Checking this machine…

1 · Login with Chrome new session

  1. Click the gold Login with Chrome button
  2. Chrome opens (private yt_final profile)
  3. Sign into YouTube as usual
  4. Quit that browser with quit it fully
  5. Click Test cookies

2 · Import from browser already signed in

  1. Confirm YouTube is signed in (daily Chrome)
  2. Fully quit the browser - quit it fully
  3. Pick browser → Import from browser
  4. Click Test cookies

3 · cookies.txt file

  1. Export with a “Get cookies.txt LOCALLY” extension
  2. Import file or paste → Import file
  3. Click Test cookies

After any method, status should show valid: true. Cookies expire - if downloads fail auth again, re-login or re-import. Terminal: python yt_final.py auth login

Speed test

why are downloads slow — and the one thing to press

This checks your connection, then downloads a real YouTube video two ways — straight, and through the built-in bypass — so it can tell you exactly what's slowing you down and the single fix that helps most. It takes about a minute and touches nothing until you press a button on a result.

Also test a proxy or VPN optional

Want to see how a proxy or VPN would do? Two ways:

  1. A proxy — pick a type and paste IP:PORT (passwordless). The test measures YouTube through it too, alongside straight and bypass.
  2. A VPN — turn your VPN on, then run the test. It detects the VPN exit and measures YouTube through it. Turn the VPN off and re-run to compare against your real ISP.

Main compose

              
Always visible on Workspace → Compose job. Top to bottom matches the form.


              

                
ComposeYouTube URL(s) — one per line

                
YouTube URL(s)

                
Big text box at the top. One link per line = one job. Playlists and channel pages work too.

              


              

                
ComposeMax resolution

                
Max resolution

                
First dropdown under the URL. Cap how tall the video can be. Higher = sharper and larger files.

                

                  
1080pBest everyday for editing. Pairs with H.264, reasonable size.

                  
bestHighest YouTube offers (often 4K). Big files.

                  
4k · 1440p · 720p · 480pHard ceiling at that height.

                  
audioSound only. Then set Audio file format under Advanced → Audio & subtitles.

                

              


              

                
ComposePreferred stream

                
Preferred stream

                
Middle dropdown. Which YouTube format family to grab. Not the re-encode codec (that is Encoder profile when Delivery is Re-encode).

                

                  
H.264 — edit-readyPlays and edits almost everywhere. Best default. Usually max 1080p.

                  
AV1 — smaller / archiveSmaller files for the same look. Good for 4K archives.

                  
VP9 — common 4KYouTube’s usual 4K stream. Larger than AV1.

                  
Any — largest availableNo preference; take the biggest / best listed stream.

                

              


              

                
ComposeDelivery

                
Delivery

                
Third dropdown. What happens after download.

                

                  
Remux — keep original (fast)Default. Repackage + optional chapters/metadata. No quality loss.

                  
Re-encode — editor profileTranscode with Encoder profile. Masters, smaller files, burn-in subs. Shows Encoder profile.

                  
Download only — no processingRaw download as-is (skips remux extras).

                

              


              

                
ComposeEncoder profileonly when Delivery = Re-encode

                
Encoder profile

                
Encoder preset when re-encoding. List fills after GPU detect.

                

                  
premiere_h264_* / nvenc_*NVIDIA GPU (fast). Premiere-friendly H.264 / HEVC / AV1.

                  
amf_* · qsv_*AMD or Intel hardware encoders.

                  
cpu_h265 · cpu_av1*Software encode (slower, high quality / smaller).

                  
prores_* · dnxhr_* · dnxhd_*Editing masters (.mov) for Resolve, Premiere, Avid.

                

                
Missing encoder → automatic fallback (e.g. AV1 → HEVC → H.264).

              


              

                
ComposeCheck available formats

                
Check available formats

                
Button under the three dropdowns. Asks YouTube what heights this URL offers (no download). Use before 4K / AV1 / VP9; can set Max resolution for you.

              


              

                
ComposeSave to folder

                
Save to folder

                
Path field with Browse…. Where finished files land. Default downloads. Created if missing.

Queue job

                
Green ▶ button. Adds job(s) to the queue. Progress shows in the Pipeline panel on the right.

Downloads feel slow or stuck?

                
Often YouTube is throttling your IP after many pulls. Fix: sign in with cookies on the Auth tab (Premium helps more). Clear Time range if you set a clip - full videos use the fast path. Leave the IP alone for a while if it still crawls.
